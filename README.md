## Description
This project demonstrates JSON data handling,
JavaScript fetch API, and jQuery DOM manipulation.

## Files
1. books.json - JSON dataset containing two books.
2. books.html - Retrieves and displays JSON data.
3. jquery-dom.html - Demonstrates jQuery DOM operations.

## How to Run

1. Download or clone this repository.
2. Open the project folder using Visual Studio Code.
3. Install the Live Server extension.
4. Open books.html using Live Server.
5. Open jquery-dom.html using your browser.
